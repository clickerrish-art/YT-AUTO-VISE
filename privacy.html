Privacy Policy

Effective date: 19 November 2026.

This policy applies to SonicVhibez YouTube Automation. When authorized by the channel owner, the application accesses YouTube channel and video information needed to identify the connected channel, upload approved videos, and verify video status and metadata. It requests YouTube upload and read-only access for these functions.

Use

Google/YouTube data is used only to operate the authorized SonicVhibez publishing workflow. It is not sold, used for advertising, or used for profiling.

Storage and security

OAuth credentials for automation are configured as GitHub Actions repository secrets, not published in source code. Access is governed by repository permissions. Operational workflow records may be retained by GitHub under its service and log-retention settings. This policy does not claim a retention period controlled by GitHub.

Sharing

Google user data is processed by Google/YouTube to provide the requested API functions and by GitHub as the source repository and automation host. It is not shared with advertisers or data brokers.

Retention and choices

Users may decline authorization or revoke it at any time through Google Account security settings. Stored automation credentials can be removed from GitHub Actions secrets. GitHub may retain workflow logs subject to its own retention controls.

Contact

For privacy requests, contact the maintainer through GitHub project issues. Never post passwords or OAuth tokens publicly.
