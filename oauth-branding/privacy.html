Privacy Policy

Application: SonicVhibez YouTube Automation
Effective date: 19 November 2026

This policy explains how SonicVhibez YouTube Automation handles information when the channel owner connects a Google Account and authorizes YouTube access.

Information accessed

Depending on the permissions approved by the user, the application may access YouTube channel and video information needed to identify the authorized channel, upload videos at the user's direction, and check the status and metadata of videos. The application requests YouTube upload and read-only permissions only for these channel-management functions.

How information is used

Google/YouTube information is used only to operate the authorized SonicVhibez publishing workflow: identify the connected channel, perform an explicitly authorized upload, and read channel or video information for operational verification. It is not used for advertising, profiling, or sale of personal information.

Storage and security

OAuth credentials used by the automation are configured as repository automation secrets in GitHub Actions rather than published in source code. Access to those secrets is controlled by the repository's GitHub permissions. The application should not place access tokens or refresh tokens in public source files or public logs. Operational workflow records may be retained by the hosting platform according to its own service and log-retention settings. This policy does not promise a retention period that the hosting platform does not control.

Sharing

Google user data is not sold or shared with data brokers or advertisers. Information is processed by Google/YouTube to provide the requested API functions and by GitHub as the repository and automation hosting provider. No other third-party sharing is intended.

Data retention and deletion

Access is retained only while the user maintains the authorization and the application configuration requires it. The user can revoke the application's Google access through their Google Account security settings. The user may also remove the stored OAuth credentials from the repository's Actions secrets. Copies of workflow logs or records may remain subject to GitHub's retention and deletion controls.

User choices

Authorization is optional. The user can decline the Google consent request or revoke access later. Revoking access prevents future API calls that require that authorization.

Children

This application is an operational channel-management tool and is not designed for children.

Changes

This policy will be updated if the application's data practices materially change. The effective date above will be revised when updates are made.

Contact

For privacy questions or requests, contact the repository maintainer through the project's GitHub issue page. Do not post OAuth tokens, passwords, or other secrets in a public issue.
